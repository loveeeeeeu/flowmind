为什么把 Workflow 和 WorkflowVersion 分开：就是上面第四部分。运行、日志、发布都需要引用一个不会变的快照/版本；
为什么画布第一版用 JSON 存：前端画布本身就是 { nodes, edges } 结构，整体保存、整体读取最简单；每个版本都是一个整体快照，本来就是一次性读写；节点类型还会频繁变化，用 JSON 不需要每次都改表结构；
为什么暂时不给 Node、Edge 单独建表：现在没有"跨工作流查询某类节点"之类的需求。拆成三张表会让保存一个版本变成一组复杂的多表写入，眼下收益小、成本高；
什么时候再拆：出现下面这类需求时。比如需要按节点类型或配置做统计和查询；单个画布太大，每次整体读写成为性能瓶颈；需要单独给某个节点记录运行状态并关联查询。
